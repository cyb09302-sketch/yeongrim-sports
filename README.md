# 영림의 스포츠

베트맨 **프로토 승부식** 전용 분석 앱 (Android)

## 📥 다운로드

### 👉 [최신 버전 다운로드](https://github.com/cyb09302-sketch/yeongrim-sports/releases/latest)

링크를 연 뒤 **Assets** 아래의 `.apk` 파일을 누르면 다운로드됩니다.

## 📲 설치 방법 (안드로이드 전용)

1. 위 링크에서 APK 파일을 다운로드합니다.
2. 다운로드 완료 알림 또는 파일 앱에서 APK를 눌러 설치합니다.
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켭니다.
4. **삼성 갤럭시에서 '기기 보호' 때문에 설치가 막히면**
   - Play 스토어에서 **Files by Google** 앱 설치
   - Files 앱 → 다운로드 폴더 → APK 파일을 눌러 설치
5. 새 버전도 같은 방법으로 설치하면 **기존 기록·즐겨찾기가 유지된 채 업데이트**됩니다.

> iPhone(iOS)은 지원하지 않습니다.

## ✨ 주요 기능

- 베트맨 승부식 회차별 경기·배당 실시간 업데이트 (진행중·예정 경기로 자동 스크롤)
- 실시간 라이브 스코어 + 문자중계·중계 찾기·OTT 바로가기
- 경기별 전력분석 · 경기정보 · 선수기록 · 선발명단 · 리그 순위
- 전문가 픽 / AI 전력분석 / **AI 추천 조합** (종목·리그·안정형·밸런스형·가치형·고배당형·2~10폴더)
- 배당률 계산기 (베트맨 조합배당·세금 규칙 반영)
- 내 조합 슬립 → **베트맨 자동 적용 · 카트담기** (베트맨 계정 연동, 로그인은 본인이 베트맨 공식 창에서 직접)
- 베팅 기록 · 적중/낙첨 자동 판정 · 카카오톡 공유
- 경기·종목·대회 즐겨찾기와 필터, 다크/라이트 모드

## ⚠️ 안내

- 본 앱은 개인 분석·기록용 도구이며 체육진흥투표권 판매·중개 기능이 없습니다. 실제 구매·결제는 베트맨(betman.co.kr)에서 본인이 직접 확인 후 진행합니다.
- 앱은 베트맨 아이디·비밀번호를 저장하지 않습니다.
- AI 분석은 통계적 참고자료이며 결과를 보장하지 않습니다.
- 미성년자는 체육진흥투표권을 구매할 수 없습니다. 도박 문제 상담: 국번없이 **1336** (한국도박문제예방치유원)
